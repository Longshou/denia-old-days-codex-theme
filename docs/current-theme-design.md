## 运行架构

主题分为两层：

1. Base Theme 提供明亮暖纸背景。
2. 可卸载 Sidecar 通过本地 CDP 注入首页、状态美术、卡片和输入区装饰。

Sidecar 不修改 Codex 应用包、签名、账户、模型或 API 配置，不发起运行时网络请求。

启动链路必须确保 LaunchAgent 在 `bootstrap` 后实际 `kickstart`，并以实时渲染器验证结果作为成功依据。

## 首页

- 首页采用《旧日斑斓》暖色剧情画面、拍立得和虹彩泡泡；Codex 原生四张建议卡在首页隐藏。
- 侧栏品牌卡只在首页出现。
- 首页允许开屏式首屏；输入区可以在下拉后的工作区域出现。
- 窄屏调整构图，不替换成孤立全身立绘。
- 仅在四个语义动作完整时隐藏其共同容器；结构不完整时不扩大隐藏范围。
- 隐藏只使用可清理的主题 class，不删除或替换原生节点；离开首页或卸载 Sidecar 后恢复原生建议卡。

## 任务页与原生布局

- 不修改任务页 `main`、分栏、输入框或原生审批卡的几何尺寸。
- 人物图是不参与布局的右侧背景装饰层。
- 原生内容、输入框和权限卡必须始终位于装饰层之上。
- 小于 `920px` 时隐藏右侧美术，优先保证工作区。
- 任务正文背景使用达妮娅双形态色板：默认浅色为珠光粉白、发色粉、蓝紫与晶体蓝；`data-denia-theme="dark"` 使用虚空海军蓝、靛蓝、钴蓝和克制粉紫。
- 背景只使用静态柔焦渐变，正文中心保持低干扰；不使用人物、手账、具象花朵、位图、动画或重复纹理。

## 原生右侧栏

- 首页和任务页共用几何识别和实际宽度状态，不依赖窗口媒体查询。
- 拖拽过程中使用与主题一致的实色遮罩隐藏画面重排；停止 `120ms` 后按面板宽高比选择素材，比例小于 `0.82` 使用笑容近景，比例大于等于 `0.82` 展示完整舞台全景。
- 宽栏使用同一舞台图的低强度 `cover` 环境层填充超宽比例，主场景使用 `contain` 保留人物、帷幕和舞台边框。
- 视觉层由 Sidecar 以绝对定位节点持有，不参与原生布局；ResizeObserver 负责拖拽遮罩、停止检测和一次性素材决策。
- 列表快捷项在零宽挂载阶段按 `ul/ol > li` 结构同步装饰，默认透明、无边框、无阴影，hover 和键盘焦点仅增加低强度底色。
- composer 内 ProseMirror 和 textarea 不再使用外溢 outline，焦点状态改由 composer 容器内部描边；宽栏状态提高输入表面的不透明度。
- 首页侧栏不显示任务状态人物；任务页人物栏保持在 `main` 背景层，原生摘要、底栏和右侧栏自然覆盖相交区域。
- 组件关闭后直接露出当前任务状态对应的图片，不重新挂载或回退图片状态。
- 检测不确定时不触碰原生侧栏；人物栏继续留在原生内容之下。
- 宽度小于 `920px` 时隐藏人物栏，优先保证工作区。
- “减少透明度”开启时隐藏两张右侧栏图片并回退纯色；“减少动态效果”开启时画面层立即切换。
- 左侧导航继续使用现有独立背景，不读取右侧栏人物资源。
- 不修改侧栏宽度、滚动、分栏、按钮、快捷键、审批卡或输入框几何。

## 状态与美术

| 状态 | 美术 |
| --- | --- |
| `staged` | 暖色花园泡泡图，低强度等待 |
| `working` | 同一暖色图，提高对比并轻微靠近工作区 |
| `approval` | 官方双形态竖幅，表达等待用户决定 |
| `error` | 独立周年插画展图，保留完整无笑意正脸与抬臂动势 |
| `complete` | 明快周年近景 |

状态判断优先级为：

1. 可见错误；
2. 可见审批、权限或确认界面；
3. 正在工作；
4. 已完成；
5. 等待。

任何可见的原生权限卡、批准按钮或确认控件都必须被识别为 `approval`，即使页面已经存在助手消息。审批检测不能只依赖 `role="dialog"` 或旧版 `data-state` 属性。

错误状态优先读取可见的结构化错误标记和 alert；只有最新助手消息中明确的命令失败段落（失败前缀、`command not found` 与非零退出状态同时存在）才作为文本兜底，普通讨论、用户消息、代码块和旧消息不会触发错误态。

## 动效与可访问性

- 状态图使用受控透明度和位移过渡，不改变页面布局。
- 支持减少动态效果和减少透明度偏好。
- 装饰节点不接管指针事件。
- 原生按钮、审批交互和键盘焦点保持可用。
- MutationObserver 保留原生 `style`、`class`、ARIA、状态和 `data-testid` 观察；主题自身节点、纯主题 class token 变化和仅含主题节点的 child-list 会被过滤。稳定首页与任务页在等价两秒观察窗口内最多增加四次 refresh。

## 验证

清理和后续修改必须验证：

- 源文件与素材哈希检查通过。
- Sidecar 静态与行为校验通过。
- 本地 Kaboo 包可以重新生成，ZIP 与目录清单一致。
- Base Theme 和 Sidecar 的实时验证均通过。
- 首页与任务页没有水平溢出。
- 审批卡出现时状态为 `approval`，右栏使用审批专用图片。
- 首页四张原生建议卡不可见，标题、项目入口、Hero 和输入区保持可见；稳定首页与任务页的 refresh 增量不超过四次。

除非用户明确要求，不上传、不推送、不创建 PR、不发布 Registry，也不擅自重启 Codex。
