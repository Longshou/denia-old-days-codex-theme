# 任务面板开关时固定主栏横向位置

## 问题

任务页已为右侧美术栏预留空间，但主栏布局仍受面板状态控制：

- 面板全部关闭时，主题使用固定宽度快照计算主栏边距。
- 置顶摘要或右侧栏打开时，主题撤销边距覆盖，主栏回到原生居中位置。
- 右侧栏收起时，主题还会播放一次补偿位移动画。
- 底部终端虽然不占横向空间，原生容器动画仍可能带动主栏。

这些状态切换导致主栏在面板开关时横向滑动。

## 设计

任务页始终使用同一套横向布局，不再按面板状态切换。

- 主栏边距继续使用现有的 `--denia-thread-content-width` 稳定宽度快照和美术栏预留宽度计算。
- 主栏外层容器始终禁用原生 `transform` 和 `transition`，避免面板动画带动横向位置。
- 删除侧栏收起过渡选择器和 `denia-old-days-sidebar-close-align` 补偿动画。
- 保留摘要、底部面板和侧栏状态检测，继续用于面板样式、美术状态与诊断。
- 不修改主栏宽度、输入框尺寸、终端高度、面板尺寸或交互。

底部终端仍由原生布局调整任务区高度，只固定主栏的横向位置。

## 性能

此次修改只收敛静态 CSS：

- 不增加 DOM 查询或几何测量。
- 不增加 `MutationObserver`、事件监听器、定时器或动画帧回调。
- 不增加逐帧位移补偿。
- 删除一段关键帧动画和一个过渡状态选择器。

运行时已有状态同步保持不变。

## 测试

- CSS 中只能保留一条任务主栏横向布局规则，且不依赖面板开关状态。
- 主栏外层的 `transform` 与 `transition` 固定覆盖不依赖面板状态。
- 不再包含侧栏收起过渡选择器或 `denia-old-days-sidebar-close-align` 关键帧。
- 任务页不得新增其他宽度、边距、内边距、网格或弹性布局覆盖。
- 运行时源码不得新增面向主栏固定功能的观察器、定时器、动画帧或几何测量。
- Sidecar 验证、项目检查和打包验证全部通过。

## 验收标准

- 底部终端、置顶摘要和右侧栏开关前后，主栏横向位置不变。
- 底部终端只改变任务区可用高度。
- 摘要和右侧栏使用已预留的右侧空间。
- 主栏宽度、输入框尺寸、美术栏和面板交互保持不变。
