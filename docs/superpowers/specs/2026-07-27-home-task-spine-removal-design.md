# 首页与任务页书脊装饰清理

## 问题

当前存在三套彼此重叠的书脊装饰：

- Base Theme 的 `art/source/background.svg` 在画布中线绘制页缝和六组环扣。
- Sidecar 的 `.denia-old-days-ds-chrome::before` 在整个视口中线重复绘制椭圆环。
- 首页 `.denia-old-days-ds-hero::before` 在首页卡片中线再次重复绘制椭圆环。

这些装饰会穿过任务正文、代码块、建议卡和输入框。首页同时显示多套环扣，层级也不清楚。

## 本轮范围

本轮只删除书脊、页缝和环扣，不更换美术资源，不新增装饰，不调整布局。

### Base Theme

- 删除 `background.svg` 的两条中线。
- 删除六组环扣路径。
- 保留暖纸底色、左右纸面轮廓、纸张阴影、横线和边缘气泡。

### Sidecar

- 删除 `.denia-old-days-ds-chrome::before` 及其窄屏覆盖。
- 删除 `.denia-old-days-ds-hero::before` 及其窄屏覆盖。
- 保留首页卡片的左右配色、拍立得、建议卡和输入区。
- 保留任务页右侧状态美术、纸雾和状态过渡。

## 资源与响应式

本轮不引入网络图片，也不制作新的手账本资源。首页和任务页先使用去除中轴装饰后的现有纸面，观察真实效果后再决定是否制作首页专用手账底板。

宽屏、紧凑桌面和窄屏使用同一套删除规则，不保留隐藏但仍可被后续断点重新启用的书脊选择器。

## 验证

- 源码检查禁止 Base Theme 再包含中线和环扣路径。
- CSS 验证禁止全屏装饰层和首页卡片生成书脊伪元素。
- 重新生成 `theme/background.jpg`、首页预览和任务预览。
- 运行完整 Sidecar 校验与 Kaboo 本地构建。
- 更新本地安装后分别检查首页和任务页：
  - 中轴没有环扣或页缝穿过内容。
  - 首页文字、照片、建议卡和输入区位置不变。
  - 任务正文、输入框和右侧状态美术位置不变。
  - 窄屏仍不显示任务状态美术。

## 验收标准

- 首页和任务页不再出现中轴书脊、椭圆环或装订线。
- 任务页只保留右侧状态美术作为人物背景。
- 本轮不出现新的美术资源、布局调整或额外装饰。
- 静态校验、构建和实时检查通过。
