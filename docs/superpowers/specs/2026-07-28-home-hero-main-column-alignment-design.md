# 首页横幅放大与主栏背景对齐

## 现状

当前实机窗口为 `1512×863px`，首页布局尺寸如下：

- 主栏视觉容器：`1272×771px`，左上角为 `(240, 92)`。
- 主题横幅：`1119×299px`，左上角为 `(316, 105)`。
- 原生标题区：宽 `1140px`，左边界为 `306px`。
- 原生输入框：宽 `1148px`，左边界为 `302px`。

横幅比原生主内容窄约 `29px`，高度只有 `299px`。右侧照片在低高度桌面规则中限制为 `440px`。

背景图由 Dream Skin 基础运行时绘制在整个 `body` 上，坐标范围包含左侧栏。横幅、标题和输入框则在左侧栏之后的主栏内居中。背景图中的纸张区域因此相对主栏向左偏，右边缘提前结束。

## 历史定位

- `ae75d1a` 新增 `min-width: 1200px` 且 `max-height: 919px` 的压缩规则，将常规横幅改为低高度布局。
- `c117c6a` 将低高度照片从 `440px` 缩到 `390px`，并继续压缩内边距和标题。
- `79b367f` 将照片恢复到 `440px`，但保留低高度压缩规则。

当前尺寸主要由 `ae75d1a` 引入的低高度规则决定。`c117c6a` 的进一步缩小已经被部分撤回。

## 方案

### 横幅

桌面横幅最大宽度从 `1120px` 调整为 `1160px`。在当前实机主栏中，横幅预计左边界为 `296px`，与原生输入框左边界相差约 `6px`。

低高度桌面规则调整为：

- 横幅宽度：`min(1160px, calc(100% - 32px))`。
- 横幅内边距：`26px 36px`。
- 两栏间距：`36px`。
- 右侧照片最大宽度：`500px`。
- 横幅预计高度：约 `340px`。
- 标题最大字号：`48px`。

照片、文案、状态标签、泡泡和宝丽来边框的内容与样式不变。

### 背景

首页宽幅背景从整窗 `body` 移到 `main.main-surface.dream-skin-home-shell`：

- `body` 只保留首页基底色，不再绘制 `--dream-skin-art`。
- 主栏继续使用 Dream Skin 原有的沉浸式渐变，并在同一背景栈中绘制 `--dream-skin-art`。
- 背景使用主栏自身的尺寸、中心点和 `cover` 规则。
- 左侧栏继续使用现有独立背景，不读取或覆盖首页主栏背景。

不修改 `art/source/background.svg`、`theme/background.jpg` 或任何官方素材。

## 响应式行为

- `>= 1200px`：使用 `1160px` 桌面横幅。
- `>= 1200px` 且高度 `<= 919px`：使用约 `340px` 高的低高度横幅和 `500px` 照片。
- `920px-1199px`：保留现有 `980px` 紧凑布局。
- `< 920px`：保留现有单栏布局、照片尺寸和泡泡位置。

背景始终以实际主栏为坐标系。侧栏宽度变化由原生主栏布局处理，不新增 JavaScript 测量。

## 变更边界

允许修改：

- `sidecar/src/denia-old-days-extension.css`
  - 首页宽幅背景的绘制目标。
  - 桌面横幅及低高度桌面横幅的尺寸。
- `sidecar/tests/validate.mjs`
  - 首页背景坐标系与横幅尺寸的回归断言。
- 本设计文档和后续实现计划。

禁止修改：

- `sidecar/src/denia-old-days-extension.js`。
- `sidecar/runtime/loader.mjs`。
- `art/`、`theme/` 和 `sidecar/assets/` 下的素材。
- `sidecar/extension.json`、打包脚本和安装脚本。
- 任务页背景、任务状态美术栏、状态映射、遮罩和过渡。
- 原生标题区、输入框、项目选择器、侧栏和滚动容器的几何尺寸。
- 首页文案、配色、字体、圆角、动画和交互。

## 测试

先在 `sidecar/tests/validate.mjs` 增加失败断言，再修改 CSS：

- 首页宽幅模式下，`body` 不再绘制背景图。
- 首页宽幅模式下，`main.main-surface.dream-skin-home-shell` 同时保留沉浸式渐变和 `--dream-skin-art`。
- 桌面横幅最大宽度为 `1160px`。
- 低高度桌面照片最大宽度为 `500px`，横幅内边距和栏间距使用设计值。
- 中等宽度与窄屏规则保持现有值。
- 现有任务页背景与状态美术断言全部通过。

实现后执行：

```bash
node scripts/check-source.mjs
node sidecar/tests/validate.mjs sidecar
npm run build:kaboo
```

安装本地包后分别验证首页和任务页。首页截图使用 `1512×863px` 窗口作为主要对照。

## 验收

- `1512×863px` 下，横幅宽度约 `1160px`，高度约 `340px`。
- 横幅与原生输入框左右边界差不超过 `8px`。
- 右侧照片宽度约 `500px`，人物主体不改变裁切位置。
- 背景纸张区域以主栏中心线布局，不再按整窗中心线向左偏。
- 左侧栏外观与修改前一致。
- 原生标题区、输入框和项目选择器的实测尺寸与修改前一致。
- 任务页背景、人物栏、状态切换和输入区与修改前一致。
- 静态检查、测试、本地构建与实机验证通过。
