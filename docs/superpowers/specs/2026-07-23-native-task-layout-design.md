# 达妮娅主题原生任务布局适配设计

## 问题

任务页样式对 `.denia-old-days-ds-task main` 和 `[role="main"]` 统一增加右侧内边距，并强制缩小、右移输入框。Codex 同时展示任务列表、侧边任务、环境面板或权限提示时会存在多个 `main` 容器，宽度覆盖误伤窄面板，导致文本被压成竖列。

## 已确认方案

采用“首页定制、任务页原生”的边界：

- 首页继续保留拍立得、手账卡片和既有明快演出。
- 任务页不修改 Codex 原生容器的 `width`、`max-width`、`margin`、`padding`、Grid 或 Flex 布局。
- 任务状态人物图继续存在，但只放在固定、不可交互、不占布局空间的装饰层。
- 输入框仅保留颜色、边框和材质样式，不再改变尺寸或位置。
- 侧栏品牌卡只在首页出现，任务页不向原生侧栏插入占位内容。
- 小窗口、分栏、弹窗和权限提示完全沿用 Codex 自己的响应式行为。

## 验收

- 样式中不存在任务页 `main` 的布局留白覆盖。
- 样式中不存在任务页输入框的宽度和外边距覆盖。
- 任务页不会创建侧栏品牌卡。
- 首页拍立得和手账卡片仍保留。
- 状态人物图仍为 `pointer-events: none` 的固定装饰层。
