# 达妮娅任务页双主题背景设计

## 目标

为具体任务界面增加一套安静、耐看的达妮娅主题背景，并为后续明暗双主题适配同时准备浅色与深色两组视觉参数。

本次改动只作用于任务页。首页的背景、Hero、素材和布局保持不变。

## 视觉方向

采用“花园虚焦色团”方向，以抽象色彩表达达妮娅两种形态的气质：

- 不使用手账、纸张、文字、人物或具象花朵。
- 不铺设可辨认的角色插画。
- 不使用重复纹理、密集线条或高对比图案。
- 使用静态、低透明度的柔焦色团表现花园、花瓣、环境光和双形态气息。

官方角色资料将达妮娅描述为会温柔微笑、说机灵玩笑、时常小睡并安静观察周围的人。她的能力和武器则同时包含泡影、暗核、侵蚀场、虚空物质、星光与华丽牢笼等意象。这种“柔软表象与不安内核”的反差是两套背景共同的设计主线。

### 浅色形态

- 基底使用珠光粉白 `#F3EDF2`，对应浅色形态的白色服装、粉色长发和柔软毛边。
- 发色粉 `#E6A8B1` 作为主要柔焦色团，位于正文主栏右上边缘，不再落入角色栏。
- 蓝紫阴影 `#5B6AAC` 对应衣装层次与蓝紫晶体饰件，以低透明度分布在正文主栏左下边缘。
- 晶体蓝 `#7EC9E2` 只用于小面积冷光，使背景保留角色的泡影和能量质感。
- 深紫 `#312C5B` 仅作为极淡的远端阴影，让浅色形态仍带有被隐藏的暗面。

### 深色形态

- 基底使用虚空海军蓝 `#0F133B`，对应暗形态背景、头发和服装中最深的蓝色，不使用纯黑。
- 主阴影使用靛蓝 `#1D255F` 与钴蓝 `#2E3B7E`，构成暗形态的主要空间层次。
- 冷晶蓝 `#5671B1` 以低透明度出现在边缘，对应晶体、星轨和共鸣能量。
- 灰莓紫 `#95678F` 与压低后的粉紫 `#BE84A4` 表达眼睛、泡影反光和不安情绪，不使用高饱和霓虹洋红。
- 淡星粉 `#D4AAC1` 只作为极小面积的暗中星光，呼应武器内部溢出的光。
- 正文中心保持接近均匀的深蓝面，深色内容表面与背景使用同一冷色中性色族。

## 共同意象

两套背景共用相同的抽象构图，使主题切换时仍能识别为同一角色：

- 大尺度虚焦花瓣色团，对应浅色形态的粉发、柔软毛边和花园氛围。
- 少量半透明泡影光斑，对应她生成并引爆残象能量泡影的能力。
- 一个远离正文中心的暗核式深色晕影，对应虚空物质、暗核和侵蚀场。
- 极少量柔和星光，对应“赝作的矮星”中从华丽牢笼内部溢出的光。

这些意象只通过渐变轮廓、透明度和色彩关系表现，不绘制具象花朵、牢笼、玩偶或武器。

## 实现边界

背景使用 CSS 多层径向渐变实现，不新增位图素材。这样可以直接复用主题变量、减少运行时资源，并让浅色与深色参数由后续主题状态统一切换。

实现应满足：

- `body` 只保留当前主题的纯色基底，柔焦渐变只绘制在任务页 `main.main-surface`。
- 选择器必须包含任务页根类 `denia-old-days-ds-task`。
- 不修改首页选择器或首页视觉节点。
- 不修改任务页 `main`、分栏、滚动容器、输入框或原生卡片的几何尺寸。
- 不新增会接管指针事件的节点。
- 不改变现有右侧状态人物栏的素材、状态映射和过渡方式。
- 背景不使用动画、滤镜动画或滚动视差。
- 大面积柔焦通过渐变尺寸与透明度实现，不对全屏滚动层应用 `filter: blur()`。

## 层级与可读性

正文内容在实测宽屏任务页中约占主表面的横向 `8%–68%`，右侧角色栏约占 `76%–100%`。现有 `82%–94%` 的主要色团会被角色图片遮住，因此采用已确认的 A 方案：

- 所有位置百分比以 `main.main-surface` 为坐标系，不以整个视口为坐标系。
- 浅色发色粉位于约 `62% 10%`，蓝紫阴影位于约 `14% 90%`，晶体蓝位于约 `64% 80%`，极淡深紫位于约 `12% 12%`。
- 深色形态复用同一空间骨架：粉紫位于约 `62% 10%`，钴蓝位于约 `14% 90%`，晶蓝位于约 `64% 80%`，灰莓紫位于约 `12% 12%`，星粉不超过 `66% 88%`。
- 主要色团不得锚定在 `76%` 以右的角色栏安全区。
- 正文中央约 `28%–54%` 保持接近纯色，避免影响长文本、代码块和终端内容。

原生内容表面与输入框继续位于背景之上。背景不会形成新的任务页内容堆叠上下文，也不会覆盖右侧状态人物栏。

浅色背景的彩色层保持低透明度。深色背景的彩色层同样保持克制，不使用外发光或高亮霓虹边缘。

## 响应式与辅助功能

- 小于 `920px` 时继续隐藏右侧状态人物栏。
- 抽象背景可保留，但进一步降低边缘色团强度，保证窄屏阅读。
- `prefers-reduced-transparency: reduce` 下退化为对应主题的纯色背景。
- `prefers-reduced-motion: reduce` 不需要额外处理，因为背景本身没有动画。

## 明暗主题接口

背景样式拆分为语义化浅色与深色变量组。当前任务实现两组完整参数；后续明暗主题任务负责将应用的实际主题状态接入对应变量组。

本次实现以 `data-denia-theme="dark"` 作为显式接口，默认仍使用浅色背景。系统深色偏好不会单独切换背景，避免在完整深色内容表面尚未接入时出现深色背景与浅色正文混用；后续双主题任务统一维护该属性。

## 调研依据

- [《鸣潮》官方达妮娅学院档案](https://wutheringwaves.kurogames.com/en/main/news/detail/4677)：角色常小睡、安静观察周围的人，能力可生成并引爆阻隔虚空物质的泡影。
- [库洛官方 Ver.3.3 角色介绍](https://prtimes.jp/main/html/rd/p/000000031.000144940.html)：角色以温柔微笑和玩笑面对周围的人；武器以华丽牢笼中的玩偶和内部溢出的星光表现梦幻与不安并存的内面。
- [库街区达妮娅图鉴](https://wiki.kurobbs.com/mc/item/1488852222116831232)：角色为热熔先天型共鸣者，属于星炬学院与残星会。
- 仓库内已固定来源的官方双形态插画：浅色形态以珠光白、发色粉、蓝紫阴影和晶体蓝为主；暗色形态以虚空海军蓝、靛蓝、钴蓝、灰莓紫和粉紫反光为主。

## 验证

实现完成后必须验证：

- 首页截图与现有首页行为未发生变化。
- 浅色与深色的主要色团在正文主栏中清晰可见，不依赖右侧角色栏露出。
- 浅色任务页正文中心无明显彩色干扰。
- 深色任务页没有纯黑底、霓虹光和低对比正文区域。
- 任务页在宽屏和窄屏均无水平溢出。
- 右侧状态人物栏的五种状态与过渡保持正常。
- 减少透明度模式使用纯色背景。
- 源文件检查、Sidecar 验证和本地构建通过。
