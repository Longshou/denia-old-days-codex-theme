# 达妮娅任务页双主题背景设计

## 目标

为具体任务界面增加一套安静、耐看的达妮娅主题背景，并为后续明暗双主题适配同时准备浅色与深色两组视觉参数。

本次改动只作用于任务页。首页的背景、Hero、素材和布局保持不变。

## 视觉方向

采用“花园虚焦色团”方向，以抽象色彩表达达妮娅两种形态的气质：

- 不使用手账、纸张、文字、人物或具象花朵。
- 不铺设可辨认的角色插画。
- 不使用重复纹理、密集线条或高对比图案。
- 使用静态、低透明度的柔焦色团表现花园、花瓣、环境光和双形态气息。

### 浅色形态

- 基底为雾青白和轻微冷调的浅灰。
- 淡粉花光位于远离正文中心的上侧或右侧边缘。
- 浅金光点保持小面积、低饱和，仅用于增加温度。
- 青绿环境色位于下侧或左侧边缘，与现有青色主题边线衔接。

### 深色形态

- 基底为深蓝黑和靛紫，不使用纯黑。
- 洋红暗辉对应幻灭形态，但降低饱和度，避免形成霓虹效果。
- 冷蓝与紫色光晕位于边缘，正文中心保持均匀、安静。
- 深色背景与后续深色内容表面使用同一冷色中性色族。

## 实现边界

背景使用 CSS 多层径向渐变实现，不新增位图素材。这样可以直接复用主题变量、减少运行时资源，并让浅色与深色参数由后续主题状态统一切换。

实现应满足：

- 选择器必须包含任务页根类 `denia-old-days-ds-task`。
- 不修改首页选择器或首页视觉节点。
- 不修改任务页 `main`、分栏、滚动容器、输入框或原生卡片的几何尺寸。
- 不新增会接管指针事件的节点。
- 不改变现有右侧状态人物栏的素材、状态映射和过渡方式。
- 背景不使用动画、滤镜动画或滚动视差。
- 大面积柔焦通过渐变尺寸与透明度实现，不对全屏滚动层应用 `filter: blur()`。

## 层级与可读性

柔焦色团集中在视口四角和两侧。任务正文中心保持接近纯色，避免影响长文本、代码块和终端内容。

原生内容表面与输入框继续位于背景之上。背景不会形成新的任务页内容堆叠上下文，也不会覆盖右侧状态人物栏。

浅色背景的彩色层保持低透明度。深色背景的彩色层同样保持克制，不使用外发光或高亮霓虹边缘。

## 响应式与辅助功能

- 小于 `920px` 时继续隐藏右侧状态人物栏。
- 抽象背景可保留，但进一步降低边缘色团强度，保证窄屏阅读。
- `prefers-reduced-transparency: reduce` 下退化为对应主题的纯色背景。
- `prefers-reduced-motion: reduce` 不需要额外处理，因为背景本身没有动画。

## 明暗主题接口

背景样式拆分为语义化浅色与深色变量组。当前任务实现两组完整参数；后续明暗主题任务负责将应用的实际主题状态接入对应变量组。

如果运行环境已有稳定、可验证的主题标记，可以在本次实现中直接绑定。否则保留显式主题接口和系统偏好回退，避免依赖不稳定的 DOM 文本或结构猜测。

## 验证

实现完成后必须验证：

- 首页截图与现有首页行为未发生变化。
- 浅色任务页正文中心无明显彩色干扰。
- 深色任务页没有纯黑底、霓虹光和低对比正文区域。
- 任务页在宽屏和窄屏均无水平溢出。
- 右侧状态人物栏的五种状态与过渡保持正常。
- 减少透明度模式使用纯色背景。
- 源文件检查、Sidecar 验证和本地构建通过。
