# 右侧栏人物皮肤设计

## 状态

- 设计方向已于 2026-07-29 确认。
- 目标为 Codex 原生右侧栏。
- 明色与深色模式共用同一张人物素材。

## 目标

使用 `art/reference/visual-library/production-ready/denia-dark-form-smile-closeup.png` 为原生右侧栏增加人物皮肤，同时保持文字清晰、原生交互不变，并继续使用 Sidecar 的本地预加载资源管线。

## 当前状态

- 原生右侧栏由 `.denia-old-days-ds-native-right-sidebar` 标记。
- 面板、分组和列表行目前使用接近不透明的纯色表面。
- 明色模式使用暖纸、晶体蓝和低强度粉色反光。
- 深色模式使用海军蓝、靛蓝和晶体蓝边界。
- 现有测试禁止所有原生侧栏使用人物资源变量。
- 素材已进入美术资料库，但尚未作为运行时构建输入。
- 运行中的右侧栏稳定宽度约为 `334px`，高度随应用窗口变化。

## 设计判断

Reading this as：为高频使用的原生右侧栏增加双主题人物皮肤，采用冷色暗形态、静态构图和高信息密度，保留原生组件结构与现有主题语义。

- `DESIGN_VARIANCE: 4`
- `MOTION_INTENSITY: 1`
- `VISUAL_DENSITY: 8`
- 模式：保守重绘
- 技术基础：现有 Sidecar、原生 CSS 和语义变量

## 方案

### 构图

- 人物图固定在右侧栏底部。
- 构建期按右侧区域裁切，优先保留眼睛、笑容和蓝色手套。
- 输出比例接近实际右侧栏，避免运行时大幅横向裁切。
- 面板使用 `cover` 和 `center bottom`，窗口高度变化时保持人物主体稳定。
- 不增加独立 DOM、伪元素或参与布局的装饰节点。

### 遮罩

图片和内容之间使用从上到下逐渐减弱的单色遮罩。

明色模式：

- 顶部使用高不透明暖白，保护标题和主要操作。
- 中部降低暖白不透明度，露出眼睛和发色。
- 底部使用带蓝灰倾向的浅色遮罩，保留手套冷光。

深色模式：

- 顶部使用高不透明海军蓝。
- 中部逐步降低遮罩强度，保留粉色眼睛。
- 底部使用深靛蓝遮罩，控制蓝色手套的亮度。

两种模式都使用单一静态遮罩，不增加模糊、滤镜、外发光或动画。

### 内容表面

- 普通分组和列表行改为半透明功能表面。
- 选中项、审批、错误、完成等语义状态继续使用高不透明表面。
- 文字、图标、焦点环和边界继续使用现有语义颜色。
- 图片不得直接承担文字对比度，遮罩和内容表面必须提供完整对比度。
- `prefers-reduced-transparency: reduce` 下回退到现有纯色表面。

### 交互与布局

- 不修改右侧栏宽度、高度、滚动、分组结构和列表布局。
- 不修改按钮、快捷键、焦点顺序、点击区域和原生状态。
- 不改变右侧栏打开、关闭和应用窗口缩放行为。
- 不修改左侧导航。
- 不修改首页背景、任务人物栏和主内容区。

## 素材管线

资料库目录继续作为不可变归档，不直接参与运行时构建。

实施时：

1. 将指定 PNG 的原始字节复制到 `art/source/official/`，文件哈希保持 `1dcbfa127968c2386ad77da325f850ad4985bccc95959d915652df36dcba2296`。
2. 在 `canon/sources.md` 记录该文件从资料库转为右侧栏构建输入。
3. 在 `scripts/release-inputs.mjs` 声明新源文件。
4. 在 `scripts/render-assets.mjs` 生成 `640×1600` 的 WebP，使用偏右裁切保留笑容，目标文件小于 `1 MiB`。
5. 在 `sidecar/extension.json` 增加独立的右侧栏资源键。
6. loader 将资源编码进安装载荷。
7. runtime 创建一次对象 URL，并设置专用 CSS 变量。
8. cleanup 移除 CSS 变量并撤销对象 URL。

运行时不读取资料库路径，不访问远程资源。

## CSS 边界

- 专用变量只允许出现在 `.denia-old-days-ds-native-right-sidebar` 及其透明度回退规则中。
- 左侧栏继续禁止使用任何人物资源变量。
- 右侧栏禁止使用首页和任务状态人物变量。
- 右侧栏背景由模式遮罩和专用人物变量组成。
- 分组和列表行只调整绘制属性，不增加布局属性。
- 原生侧栏选择器继续保持 paint-only 约束。

## 验证

### 静态验证

- 新源文件哈希与资料库文件一致。
- WebP 为 `640×1600`，文件小于 `1 MiB`。
- manifest、loader、runtime 和 cleanup 的资源契约完整。
- 所有模板占位符只出现一次。
- 左侧栏未使用人物变量。
- 右侧栏只使用专用人物变量。
- 首页和任务状态人物变量未进入右侧栏。
- 侧栏规则未增加布局属性。

### 运行时验证

- Sidecar 安装、启动和实时验证通过。
- 明色模式右侧栏显示人物皮肤。
- 深色模式右侧栏显示人物皮肤。
- 标题、列表、按钮、图标和状态文字保持可读。
- 选中、hover、审批、错误和完成状态可辨认。
- 右侧栏打开、关闭和滚动没有跳动。
- 左侧栏、首页、任务主栏和任务人物图无变化。
- cleanup 后图片变量和对象 URL 被移除。

### 视觉复核

- 顶部标题区不出现高对比人物细节。
- 眼睛、笑容和蓝色手套在常见窗口高度中可辨认。
- 图片不会压过任务摘要和操作按钮。
- 明色模式不出现脏灰蒙层。
- 深色模式不出现过亮蓝光或粉色外发光。

## 不在本次范围

- 新增侧栏品牌卡或人物说明。
- 根据任务状态切换右侧栏图片。
- 图片视差、呼吸、闪烁或入场动画。
- 修改原生侧栏内容和信息架构。
