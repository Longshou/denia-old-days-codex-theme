# 达妮娅泡泡拍立得与双形态视觉设计

日期：2026-07-23

状态：已实施

## 设计判断

这是保留 Codex 信息结构、重做视觉语言的纠偏设计。整体采用明快暖色的手账拍立得基调，明暗双形态通过不同工作状态切换同一角色的不同官方画面体现，不在一个画面里拼贴。

- `DESIGN_VARIANCE: 7`
- `MOTION_INTENSITY: 3`
- `VISUAL_DENSITY: 3`

## 首页

- 宽屏和紧凑版只使用《旧日斑斓》约 00:01:42 的同一张完整暖色画面。
- 紧凑版只改变裁切和相纸尺寸，不替换成透明立绘。
- P2 拍立得包含背纸、厚下边、细纸纹、内缘压痕、翘角和偏水青灰的物理阴影。
- 泡泡使用多层虹彩膜：水青边、珊瑚暗面、紫色薄膜、暖金折射和不对称高光。
- 手账装订、浅色书页和操作区继续存在，但相片不侵入按钮、标题和输入区。

## 任务状态

- `working`：保持暖色工作界面，不显示暗色舞台。
- `approval`：右侧独立美术带使用完整舞台源图的中央明亮形态裁切。
- `error`：右侧独立美术带使用同一完整舞台源图的左侧暗形态裁切。
- `complete`：暗色美术带退出，回复区域使用暖金归档纸带。

暗色美术只能位于阅读列外侧，并以明亮书页渐变形成清晰分界。

## 素材边界

- 运行时只携带 Bright 和 Dark 两张 WebP 衍生图。
- `stage-wide.webp` 等官网透明层只保留在外部资料库的 `reference-only/` 中。
- 官方共鸣者档案卡面不作为舞台主视觉使用。
- 透明立绘已从主题源码、Sidecar、构建产物和说明文件中移除。
- 运行时不发起图片网络请求。

## 响应式与可访问性

- 中等窗口保留同源横向拍立得。
- 小于 920px 时首页回到单列，拍立得以浅横幅形式保留。
- 任务暗色美术带在小窗口隐藏。
- 入场和状态过渡只改变 `transform`、`opacity` 和饱和度。
- `prefers-reduced-motion` 与 `prefers-reduced-transparency` 均有降级。

## 验收

1. 首页没有卡面、剧情截图和立绘混拼。
2. 两个首页尺寸使用同一官方剧情画面。
3. 拍立得有可辨认的真实相纸层次。
4. 泡泡不再是简单描边圆形。
5. 暗形态只在审批和错误状态进入。
6. 美术带与工作界面分区清楚。
7. 所有状态文案与截图状态一致。
8. 包作用域样式、运行时清理和离线素材加载继续通过验证。
