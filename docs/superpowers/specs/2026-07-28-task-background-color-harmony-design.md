# 达妮娅任务页背景色彩协调修正

## 问题

当前浅色任务页在主栏与右侧人物栏之间出现灰黄绿色雾带。实机检查确认这不是主栏渐变锚点问题，而是三层颜色叠加造成的：

- 人物原图左侧包含草地的黄绿与青绿色；
- 人物栏使用偏薄荷绿的半透明底色；
- `working` 状态又叠加青蓝色蒙层，并通过透明遮罩淡入主栏。

粉紫主栏会放大这组互补色的脏感，使人物栏看起来像有一条独立的竖向接缝。

## 方案比较

### 仅降低人物图饱和度

能减弱草地颜色，但薄荷绿底和青色状态蒙层仍会形成接缝；人物也会失去粉发与蓝紫饰件的辨识度。不采用。

### 继续使用暖粉底

与浅色形态的粉发直接呼应，但大面积暖粉会让长时间阅读偏闷，并继续放大原图中的浅黄区域。不采用。

### 珠光灰紫底与同色过渡桥

以接近中性的珠光灰紫作为浅色基底，只在边缘保留低彩粉、靛蓝和灰紫；深色使用墨蓝紫、靛蓝和灰莓紫。人物栏左侧从当前主题基底色开始，再过渡到人物图，不使用薄荷绿、青绿或浅黄蒙层。采用此方案。

## 视觉参数

### 浅色

- 基底：珠光灰紫 `#F2EFF4`。
- 右上：低彩粉 `rgba(205, 158, 182, .18)`，对应粉发。
- 左下：灰靛蓝 `rgba(83, 83, 139, .13)`，对应蓝紫衣装阴影。
- 右下：低彩紫蓝 `rgba(121, 126, 173, .09)`，对应晶体与眼睛反光，但不使用青色。
- 左上：极淡灰葡萄紫 `rgba(96, 77, 112, .045)`，只提供层次。
- 正文中心继续保持低对比，不增加纹理或具象元素。

### 深色

- 基底：墨蓝紫 `#12142F`，不使用纯黑和高饱和海军蓝。
- 右上：灰莓紫 `rgba(161, 107, 145, .17)`。
- 左下：靛蓝 `rgba(48, 53, 111, .44)`。
- 右下：灰紫蓝 `rgba(87, 95, 154, .18)`。
- 左上：暗葡萄紫 `rgba(118, 79, 126, .12)`。
- 小面积星粉 `rgba(190, 144, 172, .08)` 只作远端反光。

## 人物栏融合

- 人物栏背景改为低彩灰紫，不再使用 `rgba(240, 248, 247, .3)`。
- 左侧过渡的起始色改为当前主题基底的等透明度颜色，保证明暗主题都与主栏自然相接。
- 只替换现有蒙层色值，不改变各状态已有的渐变色标位置和透明度，因而不增加对人物图的覆盖范围。
- 各任务状态的第二层洗色只换成低彩粉、灰紫、靛蓝或莓紫，不使用 `--denia-cyan`、`--denia-gold`、薄荷绿或黄绿色。
- 人物图素材、背景位置、背景尺寸、透明度、滤镜与变换全部保持原样。
- 人物栏的 `42px` 遮罩、栏宽、边界、状态映射、过渡动画和交互穿透行为全部保持原样。

## 范围

- 只修改具体任务页背景与任务页人物栏的背景融合样式。
- 首页视觉、首页背景和首页布局保持不变。
- 不新增图片、节点、纹理、动画或手账元素。
- 不改变主栏、侧栏、输入框、滚动容器和卡片的几何尺寸。
- 不扩大人物栏蒙层或遮罩，不裁切、缩放、移动、降饱和或调暗人物图。
- 小于 `920px` 时人物栏仍隐藏，背景使用更低强度的紧凑渐变。
- `prefers-reduced-transparency: reduce` 继续退化为纯色任务背景。

## 验收

- 浅色任务页主栏与人物栏之间没有青绿、黄绿或独立的灰色竖向接缝。
- 浅色背景能辨认出粉、灰紫和靛蓝层次，但长文本区域不花眼。
- 深色背景沿用相同构图，表现墨蓝紫、靛蓝与灰莓紫，不出现霓虹青色。
- 人物原图仍可辨认，状态切换与过渡保持正常。
- 人物栏的可见面积与修改前逐像素使用相同的遮罩范围；素材层的计算样式保持不变。
- 首页截图和行为不发生变化。
- 静态校验、实时 Sidecar 验证与本地构建通过。
